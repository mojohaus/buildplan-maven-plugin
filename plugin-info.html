Plugin Details

This report describes goals, parameters details, requirements and sample usage of this plugin.

Goals

Goals available for this plugin:

Goal Report? Description
buildplan:help No Display help information on buildplan-maven-plugin.
Call mvn buildplan:help -Ddetail=true -Dgoal=<goal-name> to display parameter details.
buildplan:list No List plugin executions for the current project.
buildplan:list-phase No List plugin executions by phase for the current project.
buildplan:list-plugin No List plugin executions by plugin for the current project.
buildplan:report Yes Report plugin executions for the current project.

System Requirements

The following specifies the minimum requirements to run this Maven plugin:

Maven 3.5.4
JDK 1.8

Usage

You should specify the version in your project's plugin configuration:

<project>
  ...
  <build>
    <!-- To define the plugin version in your parent POM -->
    <pluginManagement>
      <plugins>
        <plugin>
          <groupId>org.codehaus.mojo</groupId>
          <artifactId>buildplan-maven-plugin</artifactId>
          <version>2.3.0</version>
        </plugin>
        ...
      </plugins>
    </pluginManagement>
    <!-- To use the plugin goals in your POM or parent POM -->
    <plugins>
      <plugin>
        <groupId>org.codehaus.mojo</groupId>
        <artifactId>buildplan-maven-plugin</artifactId>
      </plugin>
      ...
    </plugins>
  </build>
  ...
  <!-- To use the report goals in your POM or parent POM -->
  <reporting>
    <plugins>
      <plugin>
        <groupId>org.codehaus.mojo</groupId>
        <artifactId>buildplan-maven-plugin</artifactId>
        <version>2.3.0</version>
      </plugin>
      ...
    </plugins>
  </reporting>
  ...
</project>

For more information, see "Guide to Configuring Plug-ins"
